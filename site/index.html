COMPLETED PROJECT / 06

Keyless AWS CI/CD with OIDC

Done

A secure deployment platform that tests and deploys a Python Lambda application using GitHub Actions, Terraform, and AWS OpenID Connect. GitHub exchanges its OIDC token for short-lived AWS credentials, so no long-lived AWS access keys are stored in the repository or GitHub secrets.

The pipeline runs pytest, Terraform validation, and Checkov before deployment. Separate dev and prod IAM roles and state keys isolate each environment. Terraform state is stored in a private, encrypted, versioned S3 bucket with native state locking. The existing GitHub OIDC provider is reused, while deployment permissions are scoped to this project's resources.

The dev deployment passed end to end, including AWS authentication, infrastructure provisioning, and a Lambda health check. All five application tests passed; Checkov reported no failures with documented demo exceptions. Prod is configured for manual deployment. An explicit destroy workflow is included; teardown has not yet been exercised.

COMPLETED PROJECT / 07

Cloud Resume & Portfolio

Completed

A live multicloud engineering and security portfolio hosted on AWS. Amazon CloudFront delivers the website and resume over HTTPS from a private S3 bucket. Origin Access Control signs requests to S3, keeping the bucket protected from direct public access. Terraform provisions the infrastructure, while AWS CLI handles website uploads and cache invalidation.

The project includes responsive design, a downloadable resume, a certification showcase, and infrastructure source in GitHub. A repository-scoped GitHub OIDC provider and IAM deployment role are provisioned; automatic GitHub Actions deployment is a future enhancement.
